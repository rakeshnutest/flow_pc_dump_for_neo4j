## Network RCA Synthesis Prompt Contract

Required sections:
1. Intent
2. Executive Verdict
3. Baseline Path Summary
4. Expert Evidence
5. Evidence Chain
6. Ruled Out Checks
7. Confidence And Gaps
8. Customer-Safe RCA

Rules:
- Use only scoped evidence from skills and source tables.
- Preserve baseline-path order and explain why each expert ran.
- Distinguish `EVIDENCE_INSUFFICIENT`, `NO_*_EVIDENCE`, and `NO_*_OVERLAP`.
- Produce one final outcome: `Internal RCA`, `External RCA`, or `INCONCLUSIVE`.
